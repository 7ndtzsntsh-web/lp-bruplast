# lp-bruplast

Site da Bruplast Embalagens Plásticas (Brusque/SC): https://bruplast.vercel.app

Site estático (HTML + Tailwind CSS + AOS). Regras, conteúdo e cuidados: ver `CLAUDE.md`.

```bash
npm install
npm run build   # CSS + versão nos nomes dos arquivos + verificações
npm run dev     # http://localhost:4321
```
